Implement a CUDA kernel for Hopper SM90 (H200).

Based Taylor linear attention (unnormalized), BF16 contiguous inputs/output.
Q,K [B=8,H=32,N=8192,16], V/O [B,H,N,64]. For j<=i let x=dot(Q_i,K_j)/sqrt(16).
O_i=sum_{j<=i}(1+x+x*x/2)*V_j. There is no denominator or softmax; include the constant, linear and quadratic terms.
Accumulate in fp32 and round output to BF16. Inputs are generated independently for every batch/head.

Required public API:
void BasedLinearAttention(
    __nv_bfloat16 *Q, __nv_bfloat16 *K, __nv_bfloat16 *V, __nv_bfloat16 *O,
    int B, int H, int N);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
