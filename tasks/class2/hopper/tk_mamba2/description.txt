Implement a CUDA kernel for Hopper SM90 (H200).

Mamba2 SSD state-128, single shared Q/K group variant.
Q,K BF16 [B=8,1,N=8192,128], V/O BF16 [B,H=80,N,64], A fp32 negative log-decays [B,H,N].
State_(-1)=0; State_t=exp(A_t)*State_(t-1)+outer(K_t,V_t); O_t=Q_t@State_t.
Thus O_t=sum_{j<=t} dot(Q_t,K_j)*exp(sum_{u=j+1..t} A_u)*V_j. No additional softmax or scale.
Accumulate in fp32, round output to BF16. Q/K are shared across heads; A/V are not.

Required public API:
void Mamba2Forward(__nv_bfloat16* Q,__nv_bfloat16* K,__nv_bfloat16* V,
    __nv_bfloat16* O,float* A,int B,int H,int N);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
