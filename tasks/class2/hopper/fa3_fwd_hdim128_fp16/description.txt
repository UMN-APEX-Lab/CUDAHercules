Implement Hopper SM90 fwd attention, float16, head dimension 128.
Q: contiguous [1, 64, 8192, 128]; K,V: contiguous [1, 8, 8192, 128].
Query head h uses KV head floor(h / (64//8)). O has Q's shape/dtype.
Compute P = softmax(Q K^T / sqrt(128)), O = P V; non-causal (all keys visible).
LSE is fp32 natural-log sum-exp, shape [B,H,Sq], not log2.
Reference and solution use cold L2 and the minimum of identical timing trials.
Accumulate dot products and softmax in fp32. Do not quantize inputs to FP8.

void launch_fa3_fwd(
    const void* Q,
    const void* K,
    const void* V,
    void* O,
    float* lse,
    int B,
    int H,
    int Hkv,
    int Sq,

    float scale,
    cudaStream_t stream
);
