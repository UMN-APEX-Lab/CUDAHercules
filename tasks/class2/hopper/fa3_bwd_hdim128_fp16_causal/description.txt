Implement Hopper SM90 bwd attention, float16, head dimension 128.
Q: contiguous [1, 16, 4096, 128]; K,V: contiguous [1, 16, 4096, 128].
Query head h uses KV head floor(h / (16//16)). O has Q's shape/dtype.
Compute P = softmax(Q K^T / sqrt(128)), O = P V; right-aligned causal: key j is visible iff j <= i + Sk - Sq.
LSE is fp32 natural-log sum-exp, shape [B,H,Sq], not log2.
Reference and solution use cold L2 and the minimum of identical timing trials.
Accumulate dot products and softmax in fp32. Do not quantize inputs to FP8.
Given O (rounded to float16), dO and natural-log LSE, compute dQ,dK,dV.
Use delta = sum(dO * O) per row; dS = P * (dO V^T - delta).
dQ = scale*dS*K; dK = scale*dS^T*Q; dV = P^T*dO.
Scratch dsoftmax_sum is [B,H,round_up(Sq,64)] fp32 and dq_accum is
[B,H,round_up(Sq,64),D] fp32. Scratch contents on entry are unspecified;
only the three gradients are checked. All gradient elements must be written.

Required entry point:
void launch_fa3_bwd(
    const void* Q,
    const void* K,
    const void* V,
    const void* O,
    const void* dO,
    void* dQ,
    void* dK,
    void* dV,
    const float* lse,
    float* dsoftmax_sum,
    float* dq_accum,
    int B,
    int H,
    int Sq,
    int Sk,
    int D,
    float scale,
    cudaStream_t stream
);
