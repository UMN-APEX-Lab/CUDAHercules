Implement a CUDA kernel for Hopper SM90 (H200).

Exponentially decayed causal linear attention, BF16 Q,K,V,O[B=4,H=32,N=16384,D=128], slopes positive fp32 [H].
O_i=sum_{j<=i} exp(-slopes[h]*(i-j))*dot(Q_i,K_j)*V_j. No softmax, normalization or 1/sqrt(D) scale.
Accumulate in fp32, round output to BF16. O is output-only even though the reference internally zeros its TMA-reduction destination.

Required public API:
void LinearAttention(
    __nv_bfloat16 *Q, __nv_bfloat16 *K, __nv_bfloat16 *V, __nv_bfloat16 *O,
    float *slopes,
    int B, int H, int N, int D);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
