Implement a CUDA kernel for Hopper SM90 (H200).

Hedgehog hybrid normalized attention, BF16 Q,K,V,O[B=8,H=32,N=8192,128].
Q_map,K_map are BF16 [H,128,64]. phi(x,map)=concat(softmax(x@map),softmax(-(x@map))).
For query i, window keys are max(0,64*floor(i/64)-64)..i (previous and current 64-token blocks).
Window weights = beta[h]*exp(dot(Q_i,K_j)/sqrt(128)-max_window_logit_i).
For older keys use alpha[h]*dot(phi(Q_i,Q_map),phi(K_j,K_map)); alpha/beta are positive fp32 [H].
Normalize by the sum of all window and linear weights (+1e-6), multiply V and round O to BF16.
Accumulate in fp32. The reference uses BF16 tensor-core intermediates; the published tolerance accounts for their rounding.

Required public API:
void HedgehogAttention(__nv_bfloat16* Q,__nv_bfloat16* K,__nv_bfloat16* V,__nv_bfloat16* O,
    __nv_bfloat16* Q_map,__nv_bfloat16* K_map,float* alphas,float* betas,int B,int H,int N);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
