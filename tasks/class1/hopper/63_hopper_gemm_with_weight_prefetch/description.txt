Implement a CUDA kernel for Hopper SM90 (H200).

Decode FP8 GEMM in a SiLU-to-GEMM pipeline. A E4M3 row-major [M,K], B E5M2 column-major [K,N],
D BF16 column-major [M,N]. D=bf16(alpha*A@B), fp32 accumulation, beta=0; D is output-only.
Before every measured invocation the harness launches the same predecessor computing A=e4m3(SiLU(X)).
The predecessor signals programmatic launch completion; the reference may prefetch B while activation computation finishes.
A normal default-stream solution may rely on standard stream ordering; a solution using PDL must synchronize its dependency
before reading A. The reported time includes the predecessor for both reference and solution.

Required public API:
cudaError_t HopperGemmPrefetch(
    int M, int N, int K, float alpha,
    __nv_fp8_e4m3 const *A, int lda,
    __nv_fp8_e5m2 const *B, int ldb,
    float beta,
    __nv_bfloat16 *D, int ldd);

Default cases (m, n, k):
{"decode_16",16,8192,8192}
{"decode_64",64,28672,8192}
{"decode_128",128,8192,28672}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
