Implement a CUDA kernel for Hopper SM90 (H200).

FP8 E4M3 GEMM with fp32 accumulation and BF16 output. A row-major [M,K], B row-major [N,K], C BF16 row-major [M,N].
C=bf16(A@B^T). Only the output is BF16; input pointers remain E4M3. All output elements must be written.

Required public API:
void Fp8Gemm(__nv_fp8_e4m3 *A, __nv_fp8_e4m3 *B, __nv_bfloat16 *C, int M, int N, int K);

Default cases (label, M, N, K):
run_benchmark<matmul_template<8>>("custom",atoi(argv[1]),atoi(argv[2]),atoi(argv[3]));
run_benchmark<matmul_template<8>>("fp8_decode", 128, 8192, 8192);
run_benchmark<matmul_template<8>>("fp8_prefill", 8192, 28672, 8192);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
