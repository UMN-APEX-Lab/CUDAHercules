Implement a CUDA kernel for Hopper SM90 (H200).

N-axis gather/GEMM/scatter fusion. A is fp16 row-major [M,K], B fp16 column-major [K,N_orig].
gather_indices and scatter_indices are device arrays of length index_size, with distinct indices in each array.
For logical column j: D[i + scatter_indices[j]*ldd] = half(alpha*sum_k A[i*lda+k]*B[k+gather_indices[j]*ldb]).
D is fp16 column-major [M,N_orig]; lda=ldb=K, ldd=M, beta=0. Every selected column must be written;
unselected columns start at zero and must remain zero. Accumulate in fp32. For MoE token routing, view A as row-major weights [N_out,K], B as row-major tokens [T,K], and D as row-major [T,N_out].
Gather/scatter then select token rows in the transposed GEMM view. Defaults use N_out=1536/2048, T=4096..32768, K=1536/2048.

Required public API:
cudaError_t HopperGatherScatterGemm(
    int M, int index_size, int K, float alpha,
    __half const *A, int lda,
    __half const *B, int ldb,
    int const *gather_indices,
    float beta,
    __half *D, int ldd,
    int const *scatter_indices);

Default cases (m, n_orig, k, index_size):
{"moe_decode",1536,4096,2048,2048}
{"moe_prefill",1536,32768,2048,16384}
{"moe_down",2048,16384,1536,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
