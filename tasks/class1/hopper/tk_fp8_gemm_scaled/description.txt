Implement a CUDA kernel for Hopper SM90 (H200).

Token/channel scaled FP8 GEMM. A E4M3 row-major [M,K], B E4M3 row-major [N,K], C fp32 row-major [M,N].
A_scale fp32 [M], B_scale fp32 [N]. C[m,n] = A_scale[m]*B_scale[n]*sum_k float(A[m,k])*float(B[n,k]).
Accumulate in fp32. The oracle uses the actual quantized operands and scales, not original unquantized inputs.

Required public API:
void Fp8GemmScaled(__nv_fp8_e4m3 *A, __nv_fp8_e4m3 *B, float *C, float *A_scale, float *B_scale, int M, int N, int K);

Default cases (label, M, N, K):
run_benchmark<matmul_template<8>>("custom",atoi(argv[1]),atoi(argv[2]),atoi(argv[3]));
run_benchmark<matmul_template<8>>("fp8_scaled_decode", 128, 8192, 8192);
run_benchmark<matmul_template<8>>("fp8_scaled_prefill", 8192, 28672, 8192);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
