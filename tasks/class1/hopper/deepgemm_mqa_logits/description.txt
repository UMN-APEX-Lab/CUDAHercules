Implement a CUDA kernel for Hopper SM90 (H200).

DeepGEMM FP8 MQA indexer logits. Q E4M3 [S,H=64,D=128], KV E4M3 [Skv,D], KV_scales fp32 [Skv], weights fp32 [S,H].
For each valid key k in [cu_seqlen_ks[s], cu_seqlen_ke[s]): logits[s,k] = sum_h weights[s,h]*ReLU(sum_d Q[s,h,d]*KV[k,d]*KV_scales[k]).
Write -infinity outside the interval; NaN is never valid. Output fp32 [S,Skv], contiguous, includes padded query rows.
Intervals are right-aligned causal, exclusive upper bound. Every unmasked logit must be written with fp32 accumulation.

Required public API:
void solution_mqa_logits(
    const __nv_fp8_e4m3* q, const __nv_fp8_e4m3* kv,
    const float* kv_scales, const float* weights,
    const int* ks, const int* ke,
    float* logits,
    int seq_len, int seq_len_kv,
    int num_heads, int head_dim,
    cudaStream_t stream);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
