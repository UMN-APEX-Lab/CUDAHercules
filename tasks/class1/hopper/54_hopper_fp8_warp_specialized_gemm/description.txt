Implement a CUDA kernel for Hopper SM90 (H200).

FP8 E4M3 GEMM with fp32 accumulation/output. A row-major [M,K], B column-major [K,N], C column-major [M,N].
C = alpha*A@B + beta*C; benchmark alpha=1,beta=0. No ReLU, amax, bias or auxiliary output.
C is output-only for beta=0. The untimed independent oracle decodes the actual FP8 inputs and runs device GEMM.

Required public API:
cudaError_t HopperFp8Gemm(
    int M, int N, int K, float alpha,
    __nv_fp8_e4m3 const *A, int lda,
    __nv_fp8_e4m3 const *B, int ldb,
    float beta,
    float *C, int ldc);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
