Implement a CUDA kernel for Hopper SM90 (H200).

Block-scaled FP8 E4M3 GEMM. A row-major [M,K], B column-major [K,N], D fp32 column-major [M,N].
Both operands use 128x128 block scales. scale_A[(m/128)+kb*ceil(M/128)] and
scale_B[(n/128)+kb*ceil(N/128)] are fp32, positive, nonconstant; kb=k/128.
D[m,n]=alpha*sum_k float(A[m,k])*float(B[k,n])*scale_A[...] * scale_B[...].
FP32 accumulation, no ReLU, bias, amax or auxiliary output. beta=0. All output elements must be written.

Required public API:
cudaError_t HopperFp8BlockwiseGemm(
    int M, int N, int K, float alpha,
    __nv_fp8_e4m3 const *A, int lda, float const *scale_A,
    __nv_fp8_e4m3 const *B, int ldb, float const *scale_B,
    float *D, int ldd,
    int block_size);

Default cases (m, n, k):
{"decode",128,8192,8192}
{"prefill",8192,8192,8192}
{"mlp",8192,28672,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
