Implement a CUDA kernel for Hopper SM90 (H200).

MoE router: fp16 A row-major [M,K], B column-major [K,N], fp32 dot products, fp16 D row-major [M,N].
For each token row, select topk=8 of N=128 logits alpha*A@B, then softmax ONLY over those eight logits;
set all other probabilities to zero. Select and normalize before rounding the final probabilities to fp16.
The baseline uses CUTLASS's generic top-8 reduction enabled in a task-local header.

Required public API:
cudaError_t HopperGemmTopkSoftmax(
    int M, int N, int K, float alpha,
    __half const *A, int lda,
    __half const *B, int ldb,
    __half *D, int ldd,
    int topk);

Default cases (m, n, k):
{"router_prefill",8192,128,2048}
{"router_long",16384,128,2048}
{"router_large",16384,128,5120}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
