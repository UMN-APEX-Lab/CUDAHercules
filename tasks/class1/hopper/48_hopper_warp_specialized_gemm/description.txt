Implement a CUDA kernel for Hopper SM90 (H200).

FP32/TF32 GEMM. A is row-major [M,K], B column-major [K,N], C column-major [M,N].
C = alpha*A@B + beta*C. Accumulate in fp32; TF32 tensor-core rounding is allowed.
BF16/FP16/FP8 quantization of the input is not allowed. Reciprocal per-K power-of-two factors spanning 2^-20..2^20
exercise the FP32/TF32 exponent range while keeping dot products well scaled. beta=0 means C is output-only.

Required public API:
cudaError_t HopperGemm(
    int M, int N, int K, float alpha,
    float const *A, int lda,
    float const *B, int ldb,
    float beta, float *C, int ldc);

Default cases (m, n, k):
{"decode",128,8192,8192}
{"prefill",8192,8192,8192}
{"mlp",8192,28672,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
