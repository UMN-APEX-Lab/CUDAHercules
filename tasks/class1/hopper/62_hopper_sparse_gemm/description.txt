Implement a CUDA kernel for Hopper SM90 (H200).

Structured 2:4 sparse GEMM. A_compressed is fp16 row-major [M,K/2]; metadata is uint16 row-major [M,K/16].
Each metadata word contains four nibbles. Nibble g stores idx0 | (idx1<<2) for a group of four dense K elements;
0<=idx0<idx1<4. The two compressed values for group q are at m*(K/2)+2*q and +1.
B is fp16 column-major [K,N], D fp16 row-major [M,N]. Accumulate in fp32 and round D to fp16.
D=half(alpha*A_sparse@B), beta=0, lda for B is K, ldd=N. CUTLASS's private swizzle is converted to this canonical interface
outside timing. Compare against the correctly transposed and rounded fp32 reference.

Required public API:
cudaError_t HopperSparseGemm(
    int M, int N, int K, float alpha,
    __half const *A_compressed, uint16_t const *A_metadata,
    __half const *B, int ldb, float beta,
    __half *D, int ldd);

Default cases (m, n, k):
{"decode",128,8192,8192}
{"prefill",8192,8192,8192}
{"mlp",8192,28672,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
