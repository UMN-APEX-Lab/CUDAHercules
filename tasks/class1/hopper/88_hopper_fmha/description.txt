Implement a CUDA kernel for Hopper SM90 (H200).

CUTLASS Hopper FMHA baseline, fp16 contiguous Q[B,H,Sq,D], K/V[B,H,Sk,D], O[B,H,Sq,D].
Compute O=softmax(Q@K^T/sqrt(D))@V with fp32 dot products, softmax and accumulation, then round to fp16.
The default workloads use non-causal multi-head attention (Hq=Hkv), D=128, long context.
This ABI does not provide GQA or causal masking; those are explicitly covered by the FA3 tasks.
All output elements must be written. FP8 quantization of fp16 inputs is forbidden.

Required public API:
cudaError_t HopperFmha(
    int batch, int num_heads, int seq_q, int seq_k, int head_dim,
    __half const *Q, __half const *K, __half const *V, __half *O);

Default cases (b, h, q, k, d):
{"vision_prefill",1,16,8192,8192,128}
{"cross_attention",1,32,4096,8192,128}
{"long_prefill",1,16,16384,16384,128}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
