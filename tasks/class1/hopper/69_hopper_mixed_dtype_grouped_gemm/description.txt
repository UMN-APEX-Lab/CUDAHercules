Implement a CUDA kernel for Hopper SM90 (H200).

Grouped W8A16 GEMM for uneven expert token counts. A_ptrs point to fp16 row-major [M_g,K_g],
B_ptrs to signed INT8 column-major [K_g,N_g], D_ptrs to fp16 row-major [M_g,N_g].
Ms,Ns,Ks,ldas,ldbs,ldds and pointer arrays are DEVICE arrays. lda=ldb=K_g, ldd=N_g.
D=half(alpha*sum_k float(A)*float(B)), fp32 accumulation, beta=0. There are no weight scales in this ConvertOnly variant.
Reference validation and timing use these exact same inputs and operation; do not reinterpret FP8 bytes as int8.

Required public API:
cudaError_t HopperMixedGroupedGemm(
    int problem_count,
    int const *Ms, int const *Ns, int const *Ks,
    float alpha,
    __half const **A_ptrs, int const *ldas,
    int8_t const **B_ptrs, int const *ldbs,
    float beta,
    __half **D_ptrs, int const *ldds);

Default cases (m, k, groups):
{"moe_decode",    128,  2048, 16}
{"moe_prefill",   1024,  2048, 16}
{"moe_large",   2048,  4096, 8}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
