Implement a CUDA kernel for Hopper SM90 (H200).

Pointer-array batched fp16 GEMM with fp32 accumulation and fp16 output.
A_ptrs/B_ptrs/D_ptrs are device arrays of device pointers. All batch elements have common M,N,K.
A row-major [M,K], B column-major [K,N], D column-major [M,N]; lda=ldb=K, ldd=M.
D = half(alpha*A@B), beta=0. Inputs differ across batch elements. All outputs must be written.

Required public API:
cudaError_t HopperPtrArrayBatchedGemm(
    int M, int N, int K, int batch,
    float alpha,
    __half const **A_ptrs, int lda,
    __half const **B_ptrs, int ldb,
    float beta,
    __half **D_ptrs, int ldd);

Default cases (m, n, k, batch):
{"expert_decode",   128, 1536, 2048, 128}
{"expert_prefill",  1024, 1536, 2048, 128}
{"expert_large",  2048, 1536, 2048, 32}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
