Implement a CUDA kernel for Hopper SM90 (H200).

Split-half rotary embedding, BF16 inputs/output, fp32 intermediate arithmetic.
x/out contiguous [B=1,H=72,N=16384,D=128]; sin_table/cos_table are BF16 [N,D/2], shared across batch/head.
For d<D/2: out[...,d]=bf16(x[...,d]*cos[pos,d] - x[...,d+D/2]*sin[pos,d]);
out[...,d+D/2]=bf16(x[...,d+D/2]*cos[pos,d] + x[...,d]*sin[pos,d]).
Position tables encode position IDs 8192..24575. Do not pair adjacent elements. All heads have independent inputs.

Required public API:
void FusedRotary(
    __nv_bfloat16 *out, __nv_bfloat16 *x,
    __nv_bfloat16 *sin_table, __nv_bfloat16 *cos_table,
    int B, int H, int N, int D);

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
