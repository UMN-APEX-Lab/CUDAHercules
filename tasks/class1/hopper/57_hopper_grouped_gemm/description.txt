Implement a CUDA kernel for Hopper SM90 (H200).

Grouped FP8 MoE GEMM. A is E4M3 row-major [M_g,K_g]; B is E5M2 column-major [K_g,N_g].
D is fp16 column-major [M_g,N_g], fp32 accumulation, D=half(alpha*A@B), beta=0.
Ms,Ns,Ks,ldas,ldbs,ldds and pointer arrays are on device. Each group may have a different M; do not assume uniform groups.
lda=ldb=K_g, ldd=M_g. Every output must be written; zero-row groups, when supplied, require no work.

Required public API:
cudaError_t HopperGroupedGemm(
    int problem_count,
    int const *Ms, int const *Ns, int const *Ks,
    float alpha,
    __nv_fp8_e4m3 const **A_ptrs, int const *ldas,
    __nv_fp8_e5m2 const **B_ptrs, int const *ldbs,
    float beta,
    __half **D_ptrs, int const *ldds);

Default cases (m, n, k, groups):
{"moe_decode",128,1536,2048,16}
{"moe_prefill",1024,1536,2048,32}
{"moe_large",2048,1536,2048,16}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
