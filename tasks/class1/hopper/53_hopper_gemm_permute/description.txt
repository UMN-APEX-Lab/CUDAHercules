# Task: 53_hopper_gemm_permute

## Target Hardware
NVIDIA Hopper GPU (SM90).


Hopper strided batched GEMM, half-precision, row-major layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp16.h>

cudaError_t HopperGemmPermute(
    int M, int N, int K, int batch, float alpha,
    __half const *A, int lda,
    __half const *B, int ldb,
    float beta,
    __half *D, int ldd);
```

## Operation

For each batch b in [0, batch):
  D[b] = alpha * A[b] * B[b] + beta * D[b]

Where per batch:
- A[b] is M x K
- B[b] is K x N
- D[b] is M x N

## Data Types

- All matrices A, B, D: `__half` (FP16)
- Scalars alpha, beta: `float`
- Accumulation: `float`

## Memory Layout

All per-batch matrices are **row-major**, stored contiguously:
- A: Batch b starts at `A + b * M * K`. Element (i,k) at `A[b*M*K + i*lda + k]`.  lda = K.
- B: Batch b starts at `B + b * K * N`. Element (k,j) at `B[b*K*N + k*ldb + j]`.  ldb = N.
- D: Batch b starts at `D + b * M * N`. Element (i,j) at `D[b*M*N + i*ldd + j]`.  ldd = N.

## Test Sizes

- small: M=128, N=128, K=64, batch=4
- medium: M=512, N=512, K=256, batch=16
- large: M=2048, N=2048, K=1024, batch=4
