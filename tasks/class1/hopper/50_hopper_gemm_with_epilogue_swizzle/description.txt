Implement a CUDA kernel for Hopper SM90 (H200).

INT8 GEMM with INT32 output/accumulation. A row-major [M,K], B column-major [K,N], D column-major [M,N].
D = alpha*A@B + beta*D. Results must be exact. This task measures integer GEMM with a cached cuBLASLt baseline;
there is no requirement to reproduce a particular internal swizzle. beta=0 means D is output-only.

Required public API:
cudaError_t HopperEpilogueSwizzleGemm(
    int M, int N, int K, int32_t alpha,
    int8_t const *A, int lda,
    int8_t const *B, int ldb,
    int32_t beta, int32_t *D, int ldd);

Default cases (m, n, k):
{"decode",128,8192,8192}
{"prefill",8192,8192,8192}
{"mlp",8192,28672,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
