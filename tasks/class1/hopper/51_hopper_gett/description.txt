Implement a CUDA kernel for Hopper SM90 (H200).

Generalized tensor contraction, fp16 A/B/C, fp32 output/accumulation.
Contract over two K modes d=128 and h=K/128; K is a multiple of 128.
A[s,d,h] has address s + M*(d + 128*h). B[d,o,h] has address d + 128*(o + N*h).
C and D have address s+M*o. D[s,o] = alpha*sum_{h,d} A[s,d,h]*B[d,o,h] + beta*C[s,o].
The B tensor is permuted relative to ordinary column-major GEMM. lda/ldc/ldd=M; ldb=K is retained for ABI compatibility;
B's address formula above is authoritative. D is output-only.

Required public API:
cudaError_t HopperGett(
    int M, int N, int K, float alpha,
    __half const *A, int lda,
    __half const *B, int ldb,
    float beta,
    __half const *C, int ldc,
    float *D, int ldd);

Default cases (m, n, k):
{"decode",128,8192,8192}
{"prefill",8192,8192,8192}
{"mlp",8192,28672,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
