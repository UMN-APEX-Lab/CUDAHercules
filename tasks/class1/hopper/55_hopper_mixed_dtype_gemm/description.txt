Implement a CUDA kernel for Hopper SM90 (H200).

W8A16 mixed GEMM. A is fp16 row-major [M,K], B is actual signed INT8 column-major [K,N].
scale_B and zero_B are fp16 MN-major arrays [ceil(K/group_size),N], index n + (k/group_size)*N.
Dequantize using B_half[k,n] = half(float(scale_B[idx])*float(B[k+n*ldb]) + float(zero_B[idx])).
D is fp16 row-major [M,N]: D[m,n] = half(alpha*sum_k A[m,k]*B_half[k,n]).
Accumulate in fp32. beta=0 in all benchmark cases; D is output-only. No FP8 reinterpretation is used.

Required public API:
cudaError_t HopperMixedDtypeGemm(
    int M, int N, int K,
    float alpha,
    __half const *A, int lda,
    int8_t const *B, int ldb,
    __half const *scale_B,
    __half const *zero_B,
    int group_size,
    float beta,
    __half *D, int ldd);

Default cases (m, n, k):
{"decode",128,8192,8192}
{"prefill",8192,8192,8192}
{"mlp",8192,28672,8192}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
