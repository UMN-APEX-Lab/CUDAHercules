Hyperconnection Prenorm GEMM (from DeepGEMM / DeepSeek)

## Target Hardware
NVIDIA Hopper GPU (SM90).


Fused kernel that computes two operations simultaneously:
  D[m, n] = A[m, k] @ B[n, k]^T      (TF32 matrix multiply)
  sqr_sum[m] = sum(A[m, :]^2)          (per-row L2 norm squared)

Inputs:
  a:       row-major matrix, shape (M, K), dtype bfloat16
  b:       row-major matrix, shape (N, K), dtype float32
  M:       number of rows in A (varies: 1024, 4096, 8192)
  N:       24 (fixed, narrow output)
  K:       7168 (fixed)

Outputs:
  d:       row-major matrix, shape (M, N), dtype float32
  sqr_sum: vector, shape (M,), dtype float32

Key constraints:
  - N is very small (24) — requires efficient narrow-matrix handling
  - K is large (7168) — compute-bound along reduction dimension
  - Both outputs must be computed in a single kernel launch
  - A is bfloat16 but math is done in TF32 precision
  - B is float32

Function signature for your solution (in solution.h):
  void solution_hc_prenorm_gemm(
      const __nv_bfloat16* a,  // [M, K], row-major
      const float* b,          // [N, K], row-major
      float* d,                // [M, N], row-major
      float* sqr_sum,          // [M]
      int M, int N, int K,
      cudaStream_t stream);
