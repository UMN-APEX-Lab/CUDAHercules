Implement a CUDA kernel for Hopper SM90 (H200).

Grouped block-scaled FP8 E4M3 MoE GEMM, fp32 accumulation, BF16 column-major D.
Device pointer arrays and dimension/stride arrays specify unequal groups. A row-major [M_g,K_g], B column-major [K_g,N_g].
Activation scales have granularity 1x128: scale_A[m + kb*M_g]. Weight scales have granularity 128x128:
scale_B[(n/128) + kb*ceil(N_g/128)]. Both are positive nonconstant fp32. kb=k/128.
D[m,n]=bf16(alpha*sum_k A[m,k]*B[k,n]*scale_A[...]*scale_B[...]), beta=0.
lda=ldb=K_g, ldd=M_g; all outputs must be written.

Required public API:
cudaError_t HopperFp8BlockwiseGroupedGemm(
    int problem_count,
    int const *Ms, int const *Ns, int const *Ks,
    float alpha,
    __nv_fp8_e4m3 const **A_ptrs, int const *ldas,
    float const **scale_A_ptrs,
    __nv_fp8_e4m3 const **B_ptrs, int const *ldbs,
    float const **scale_B_ptrs,
    __nv_bfloat16 **D_ptrs, int const *ldds,
    int block_size);

Default cases (m, n, k, groups):
{"moe_decode",128,1536,2048,16}
{"moe_prefill",1024,1536,2048,32}
{"moe_large",2048,1536,2048,16}

The harness generates fractional random inputs, poisons output-only buffers, and rejects nonfinite results.
Reference and solution use the same cold-L2 timing policy and per-case minimum; every reported case contributes to the geometric-mean speedup.
