# Task: 32_basic_trmm

Double-precision Triangular Matrix Multiply (TRMM), column-major layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>

cudaError_t Dtrmm(
    int M, int N,
    double alpha,
    double const *A, int lda,
    double const *B, int ldb,
    double *C, int ldc);
```

## Operation

C = alpha * A * B

Where:
- A is M x M, lower-triangular (upper triangle is zero)
- B is M x N
- C is M x N

## Data Types

All matrices are `double` (FP64).

The result must be FP64-accurate: it is checked against an FP64 reference with the tolerance
below, which plain FP32 (or lower-precision) computation cannot meet. How FP64 accuracy is
reached is up to you: native FP64 arithmetic, or emulating FP64 with lower-precision units
(e.g. double-float arithmetic, or Ozaki-style splitting on tensor cores), are both allowed as
long as the result meets the tolerance.

## Memory Layout

All matrices are **column-major**:
- A: Element (i,k) at `A[i + k * lda]`.  lda >= M.  Only lower triangle (i >= k) is non-zero.
- B: Element (k,j) at `B[k + j * ldb]`.  ldb >= M.
- C: Element (i,j) at `C[i + j * ldc]`.  ldc >= M.

## Build & Test

```bash
make test                    # requires solution.h in task directory
./test                       # default: runs small/medium/large sizes
./test 4096 4096             # custom single size: M N
./test 4096 4096 1.1 20     # M N alpha iterations
```

Default run: alpha = 1.1, lda = ldb = ldc = M, at three problem sizes
(small: M=N=1024, medium: M=N=4096, large: M=4096 N=8192).
The lower triangle of A and all of B hold pseudo-random FP64 values in [-1, 1)
(full 52-bit mantissa); the upper triangle of A is zero. C is output-only: every element
must be written (its initial contents are undefined).

Correctness is verified against a reference implementation at every size: each element
must satisfy |C - C_ref| <= 1e-10 * max|C_ref| (NaN/Inf fail).
Performance is timed for both reference and your solution at each size.

CUTLASS headers are available on the include path.
