# Task: 26_ampere_wgrad_mainloop_fusion

Conv2D weight gradient (wgrad) with a fused per-channel scale + bias + ReLU applied to the input
activations. FP16 inputs, FP32 weight gradient, NHWC layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp16.h>

cudaError_t Conv2dWgradScaleBias(
    __half const *input, __half const *grad_output,
    __half const *scale, __half const *bias,
    float *grad_weight,
    int N, int C, int H, int W, int K, int R, int S,
    int pad_h, int pad_w, int stride_h, int stride_w);
```

## Operation

Fused conv2d weight gradient with per-channel scale, bias, and ReLU applied to the input
activations BEFORE computing the weight gradient:

1. Transform input:  transformed[n][h][w][c] = max(0, scale[c] * input[n][h][w][c] + bias[c])
2. Compute wgrad:    grad_weight[k][r][s][c] = sum_{n,p,q} grad_output[n][p][q][k] * transformed[n][h][w][c]

Where h = p*stride_h + r - pad_h, w = q*stride_w + s - pad_w.
Output dimensions: P = (H + 2*pad_h - R) / stride_h + 1, Q = (W + 2*pad_w - S) / stride_w + 1.
Zero padding applies to the transformed activations (padded positions contribute 0, they are not
transformed). Every grad_weight element must be written (the output buffer is not
zero-initialized).

## Data Types and Precision

- input:       `__half` (FP16) -- NHWC layout, the forward-pass activations
- grad_output: `__half` (FP16) -- NHWC layout (N x P x Q x K)
- scale:       `__half` (FP16) -- 1D vector of length C
- bias:        `__half` (FP16) -- 1D vector of length C
- grad_weight: `float`  (FP32) -- NHWC-style layout (K x R x S x C)

The transformed activation is an FP16-precision value (computed in FP16 or FP32; it may be rounded
to FP16). The reduction over N*P*Q must multiply FP16-precision operands and accumulate in FP32
(or higher precision). Lower-precision arithmetic is not allowed even if it passes the tolerance:
no FP16 accumulation (also not for partial sums), no products rounded to FP16, and no BF16, FP8,
INT8 or other narrower operands.

## Memory Layout

NHWC layout for all 4D tensors:
- input:       N x H x W x C. Element (n,h,w,c) at offset ((n*H+h)*W+w)*C+c.
- grad_output: N x P x Q x K. Element (n,p,q,k) at offset ((n*P+p)*Q+q)*K+k.
- grad_weight: K x R x S x C. Element (k,r,s,c) at offset ((k*R+r)*S+s)*C+c.
- scale, bias: 1D vectors indexed by channel c.

## Problem Sizes

All 3x3 filters, pad = 1, stride 1 (training):
- resnet50_conv2_b256: N=256, H=W=56,  C=K=64  (ResNet-50 stage-2 3x3 conv, training batch 256)
- resnet50_conv4_b256: N=256, H=W=14,  C=K=256 (ResNet-50 stage-4 3x3 conv, training batch 256)
- sdxl_unet_128_b8:    N=8,   H=W=128, C=K=320 (SDXL UNet fine-tuning at 1024x1024: 128x128 latents, batch 8)

## Correctness

Two input sets are used, both with random values using the full FP16 mantissa:
- set 1 (plain): input, grad_output and bias uniform in [-1, 1), scale uniform in [0.25, 2);
- set 2 (folded BatchNorm, as in a trained CNN): the activations are raw conv outputs with
  per-channel statistics, input[..][c] = mu_c + sd_c * u (u uniform in [-1, 1), sd_c in
  [0.25, 2), |mu_c| <= sd_c), and scale/bias are the folded BatchNorm parameters
  scale_c = gamma_c / sqrt(var_c + 1e-5), bias_c = beta_c - mu_c * scale_c (var_c = sd_c^2 / 3,
  beta_c in [-0.5, 0.5)). gamma_c is negative for about 1 in 6 channels and exactly 0 for about
  1 in 32 channels (pruned channels), so scale takes negative values and exact zeros, and bias
  can be positive for a zero scale. grad_output uniform in [-1, 1).
Both sets are checked once before timing, and the timed calls alternate between them (each with
its inputs rewritten into the same buffers). Every grad_weight element is compared with an
FP64 result in which the transformed activation is rounded once to FP16, and must satisfy

  |grad_weight - expected| <= 5e-6 * sum_{n,p,q} |dy * t| + 1.97e-3 * sqrt(sum_{n,p,q} (dy * t)^2)

(dy = grad_output, t = transformed activation; the second term covers rounding t to FP16 or
keeping it in FP32). NaN/Inf fail; the output buffer is filled with NaN before each call. Every
timed call is verified as well.
