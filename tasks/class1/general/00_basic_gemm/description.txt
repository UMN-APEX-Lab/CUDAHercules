# Task: 00_basic_gemm

Single-precision General Matrix Multiply (SGEMM), column-major layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>

cudaError_t SgemmNN(
    int M, int N, int K,
    float alpha,
    float const *A, int lda,
    float const *B, int ldb,
    float beta,
    float *C, int ldc);
```

## Operation

C = alpha * A * B + beta * C

Where:
- A is M x K
- B is K x N
- C is M x N

## Data Types and Precision

All matrices are `float` (FP32).

The result must be FP32-accurate: it is checked against an FP64 reference with the tolerance
below, which single-pass lower-precision computation cannot meet. How FP32 accuracy is reached is
up to you: native FP32 arithmetic, or emulating FP32 with lower-precision units (e.g. 3xTF32 or
multi-term BF16 splitting on tensor cores), are both allowed as long as the result meets the
tolerance.

## Memory Layout

All matrices are **column-major**:
- A: Element (i,k) at `A[i + k * lda]`.  lda >= M.
- B: Element (k,j) at `B[k + j * ldb]`.  ldb >= K.
- C: Element (i,j) at `C[i + j * ldc]`.  ldc >= M.

## Build & Test

```bash
make test                    # requires solution.h in task directory
./test                       # default: runs all benchmark sizes below
./test 16384 10240 5120      # custom single size: M N K
./test 16384 10240 5120 1.0 0.0 20  # M N K alpha beta iterations
```

## Problem Sizes

The linear layers of Qwen3-32B served on one GPU (hidden 5120, 64 query / 8 KV heads of
dimension 128, FFN 25600, vocabulary 151936); M = tokens, either a 16K-token prefill chunk or
one decode step of 128 concurrent sequences:

| label            | M     | N      | K     | layer                                  |
|------------------|-------|--------|-------|----------------------------------------|
| decode_qkv       | 128   | 10240  | 5120  | fused QKV projection, decode           |
| prefill_qkv      | 16384 | 10240  | 5120  | fused QKV projection, prefill          |
| prefill_o_proj   | 16384 | 5120   | 8192  | attention output projection, prefill   |
| prefill_mlp_up   | 16384 | 51200  | 5120  | fused gate+up projection, prefill      |
| prefill_mlp_down | 16384 | 5120   | 25600 | down projection, prefill               |
| decode_lm_head   | 128   | 151936 | 5120  | LM head, decode                        |

alpha = 1, beta = 0, lda = M, ldb = K, ldc = M. With beta = 0 the initial contents of C are
arbitrary finite values that must not affect the result.

## Correctness

Inputs are random FP32 values in [-1, 1) that use the full 24-bit significand. Every element of
C is compared with the exact (FP64-accumulated) result:
- every element must be finite and satisfy |C - exact| <= 1.5e-6 * sqrt(K) * RMS(exact);
- the relative Frobenius error ||C - exact|| / ||exact|| must be <= 5.5e-8 * sqrt(K).
Elements that are not written fail the check.

Performance is timed for both the reference and your solution at each size; the task score is
the geometric mean of the per-size speedups.

CUTLASS headers are available on the include path.
