# Task: 16_ampere_tensorop_conv2dfprop

Conv2D forward propagation (Fprop) with FP16 input/filter and FP32 output, NHWC layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp16.h>

cudaError_t Conv2dFpropF16(
    __half const *input, __half const *filter, float *output,
    int N, int C, int H, int W, int K, int R, int S,
    int pad_h, int pad_w, int stride_h, int stride_w,
    float alpha, float beta);
```

## Operation

output = alpha * Conv2d(input, filter) + beta * output

Where for each output element:
  output[n][p][q][k] = alpha * sum_{c,r,s} input[n][h][w][c] * filter[k][r][s][c] + beta * output[n][p][q][k]

With h = p * stride_h + r - pad_h, w = q * stride_w + s - pad_w (zero padding: out-of-bounds
positions contribute 0).

Output spatial dimensions:
  P = (H + 2 * pad_h - R) / stride_h + 1
  Q = (W + 2 * pad_w - S) / stride_w + 1

When beta == 0 the previous contents of `output` are arbitrary finite values and must not affect
the result; every output element must be written.

## Data Types and Precision

- Input tensor: `__half` (FP16)
- Filter tensor: `__half` (FP16)
- Output tensor: `float` (FP32)
- Alpha, Beta: `float`

The convolution must be computed from the FP16 operands with FP32 accumulation (FP16 x FP16
products summed in FP32 or higher precision). Lower-precision arithmetic is not allowed even if it
passes the tolerance: no FP16 products or FP16 accumulation, and no BF16, FP8, INT8 or other
narrower operands.

## Memory Layout

All tensors use **NHWC** layout:
- Input: `input[((n * H + h) * W + w) * C + c]` with shape (N, H, W, C)
- Filter: `filter[((k * R + r) * S + s) * C + c]` with shape (K, R, S, C)
- Output: `output[((n * P + p) * Q + q) * K + k]` with shape (N, P, Q, K)

## Problem Sizes

All 3x3 filters with pad = 1. Timed with alpha = 1, beta = 0.
- resnet50_conv2_b256:      N=256, H=W=56,  C=K=64,   stride 1 (ResNet-50 stage-2 3x3 conv, training batch 256)
- resnet50_conv3_down_b256: N=256, H=W=56,  C=K=128,  stride 2 (ResNet-50 stage-3 downsampling 3x3 conv, output 28x28)
- resnet50_conv4_b256:      N=256, H=W=14,  C=K=256,  stride 1 (ResNet-50 stage-4 3x3 conv)
- sdxl_unet_128:            N=4,   H=W=128, C=K=320,  stride 1 (SDXL UNet at 1024x1024: 128x128 latents,
                                                             batch 4 = 2 images x classifier-free guidance)
- sdxl_unet_64:             N=4,   H=W=64,  C=K=640,  stride 1 (SDXL UNet, 64x64 level)
- sdxl_unet_32:             N=4,   H=W=32,  C=K=1280, stride 1 (SDXL UNet, 32x32 level)

## Correctness

Inputs are random values using the full FP16 mantissa (uniform in [-1, 1)). Every output element
is compared with an FP64 result computed from the same FP16 inputs and must satisfy

  |output - expected| <= 5e-6 * (|alpha| * sum_{c,r,s} |input * filter| + |beta * output_old|)

NaN/Inf fail. Each size is checked with (alpha=1, beta=0) on an output buffer filled with garbage,
and with (alpha=0.8125, beta=-1.375) on an output buffer holding prior values. Every timed call is
verified as well.

## Build & Test

```bash
make test                    # requires solution.h in task directory
./test                       # default: runs all benchmark sizes
./test 1 56 56 64 64 3 3     # custom single size: N H W C K R S (pad R/2, stride 1)
./test 1 56 56 64 64 3 3 1.0 0.0 20  # N H W C K R S alpha beta iterations
```

Performance is timed for both the reference and your solution at each size; the task score is the
geometric mean of the per-size speedups.

CUTLASS headers are available on the include path.
