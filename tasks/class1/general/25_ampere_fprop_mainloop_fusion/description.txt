# Task: 25_ampere_fprop_mainloop_fusion

Conv2D forward propagation with a fused per-channel scale + bias + ReLU applied to the input
activations. FP16 input/filter/scale/bias, FP32 output, NHWC layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp16.h>

cudaError_t Conv2dFpropScaleBias(
    __half const *input, __half const *filter,
    __half const *scale, __half const *bias,
    float *output,
    int N, int C, int H, int W, int K, int R, int S,
    int pad_h, int pad_w, int stride_h, int stride_w);
```

## Operation

Fused conv2d forward pass with per-channel scale, bias, and ReLU applied to the input
activations BEFORE convolution:

1. Transform input:  transformed[n][h][w][c] = max(0, scale[c] * input[n][h][w][c] + bias[c])
2. Convolve:         output[n][p][q][k] = sum_{c,r,s} transformed[n][h][w][c] * filter[k][r][s][c]

Where h = p*stride_h + r - pad_h, w = q*stride_w + s - pad_w.
Output dimensions: P = (H + 2*pad_h - R) / stride_h + 1, Q = (W + 2*pad_w - S) / stride_w + 1.
Zero padding applies to the transformed activations (padded positions contribute 0, they are not
transformed). Every output element must be written (the output buffer is not zero-initialized).

## Data Types and Precision

- input:  `__half` (FP16) -- NHWC layout
- filter: `__half` (FP16) -- KRSC layout (NHWC-style)
- scale:  `__half` (FP16) -- 1D vector of length C
- bias:   `__half` (FP16) -- 1D vector of length C
- output: `float`  (FP32) -- NHWC layout

The transformed activation is an FP16-precision value (computed in FP16 or FP32; it may be rounded
to FP16). The convolution must multiply FP16-precision operands and accumulate in FP32 (or higher
precision). Lower-precision arithmetic is not allowed even if it passes the tolerance: no FP16
accumulation, no products rounded to FP16, and no BF16, FP8, INT8 or other narrower operands.

## Memory Layout

NHWC layout for all 4D tensors:
- input:  N x H x W x C. Element (n,h,w,c) at offset ((n*H+h)*W+w)*C+c.
- filter: K x R x S x C. Element (k,r,s,c) at offset ((k*R+r)*S+s)*C+c.
- output: N x P x Q x K. Element (n,p,q,k) at offset ((n*P+p)*Q+q)*K+k.
- scale, bias: 1D vectors indexed by channel c.

## Problem Sizes

All 3x3 filters with pad = 1:
- resnet50_conv2_b256:      N=256, H=W=56,  C=K=64,   stride 1 (ResNet-50 stage-2 3x3 conv, training batch 256)
- resnet50_conv3_down_b256: N=256, H=W=56,  C=K=128,  stride 2 (ResNet-50 stage-3 downsampling 3x3 conv, output 28x28)
- resnet50_conv4_b256:      N=256, H=W=14,  C=K=256,  stride 1 (ResNet-50 stage-4 3x3 conv)
- sdxl_unet_128:            N=4,   H=W=128, C=K=320,  stride 1 (SDXL UNet at 1024x1024: 128x128 latents,
                                                             batch 4 = 2 images x classifier-free guidance)
- sdxl_unet_64:             N=4,   H=W=64,  C=K=640,  stride 1 (SDXL UNet, 64x64 level)
- sdxl_unet_32:             N=4,   H=W=32,  C=K=1280, stride 1 (SDXL UNet, 32x32 level)

## Correctness

Inputs are random values using the full FP16 mantissa: input, filter and bias uniform in [-1, 1),
scale uniform in [0.25, 2). Every output element is compared with an FP64 result in which the
transformed activation is rounded once to FP16, and must satisfy

  |output - expected| <= 5e-6 * sum_{c,r,s} |t * filter| + 1.97e-3 * sqrt(sum_{c,r,s} (t * filter)^2)

(t = transformed activation; the second term covers rounding t to FP16 or keeping it in FP32).
NaN/Inf fail; the output buffer is filled with NaN before each call. Every timed call is verified
as well.
