# Task: 14_ampere_tf32_tensorop_gemm

General Matrix Multiply (GEMM) with FP32 storage and TF32 multiply precision, mixed memory
layouts: row-major A, column-major B, row-major C.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>

cudaError_t Tf32Gemm(
    int M, int N, int K,
    float alpha,
    float const *A, int lda,
    float const *B, int ldb,
    float beta,
    float *C, int ldc);
```

## Operation

C = alpha * A * B + beta * C

Where:
- A is M x K
- B is K x N
- C is M x N

## Data Types and Precision

All matrices are `float` (FP32). Products must be computed with at least TF32 precision
(operands carrying at least TF32's 10-bit mantissa and 8-bit exponent, FP32 accumulation);
lower-precision arithmetic (FP16, BF16, FP8 or INT8, including tensor-core paths that use them)
is not allowed even if it passes the tolerance.

## Memory Layout

Mixed layouts:
- A: **row-major**. Element (i,k) at `A[i * lda + k]`.  lda >= K.
- B: **column-major**. Element (k,j) at `B[k + j * ldb]`.  ldb >= K.
- C: **row-major**. Element (i,j) at `C[i * ldc + j]`.  ldc >= N.

## Build & Test

```bash
make test                    # requires solution.h in task directory
./test                       # default: runs all benchmark sizes below
./test 16384 10240 5120      # custom single size: M N K
./test 16384 10240 5120 1.0 0.0 20  # M N K alpha beta iterations
```

## Problem Sizes

The linear layers of Qwen3-32B served on one GPU (hidden 5120, 64 query / 8 KV heads of
dimension 128, FFN 25600, vocabulary 151936); M = tokens, either a 16K-token prefill chunk or
one decode step of 128 concurrent sequences:

| label            | M     | N      | K     | layer                                  |
|------------------|-------|--------|-------|----------------------------------------|
| decode_qkv       | 128   | 10240  | 5120  | fused QKV projection, decode           |
| prefill_qkv      | 16384 | 10240  | 5120  | fused QKV projection, prefill          |
| prefill_o_proj   | 16384 | 5120   | 8192  | attention output projection, prefill   |
| prefill_mlp_up   | 16384 | 51200  | 5120  | fused gate+up projection, prefill      |
| prefill_mlp_down | 16384 | 5120   | 25600 | down projection, prefill               |
| decode_lm_head   | 128   | 151936 | 5120  | LM head, decode                        |

alpha = 1, beta = 0, lda = K, ldb = K, ldc = N. With beta = 0 the initial contents of C are
arbitrary finite values that must not affect the result.

## Correctness

Inputs are random FP32 values with full 24-bit significands: A is uniform in [-2^17, 2^17) and
B is uniform in [-2^-17, 2^-17) (a wide dynamic range). Every element of C is compared with the
exact (FP64-accumulated) result:
- every element must be finite and satisfy |C - exact| <= 7e-3 * RMS(exact);
- the relative Frobenius error ||C - exact|| / ||exact|| must be <= 1.2e-3.
Elements that are not written fail the check.

Performance is timed for both the reference and your solution at each size; the task score is
the geometric mean of the per-size speedups.

CUTLASS headers are available on the include path.
