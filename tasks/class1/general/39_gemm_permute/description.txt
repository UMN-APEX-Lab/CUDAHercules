# Task: 39_gemm_permute

Half-precision General Matrix Multiply (HGEMM), row-major layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp16.h>

cudaError_t GemmPermute(
    int M, int N, int K, float alpha,
    __half const *A, int lda,
    __half const *B, int ldb,
    float beta,
    __half *D, int ldd);
```

## Operation

D = alpha * A * B + beta * D

Where:
- A is M x K
- B is K x N
- D is M x N

## Data Types

All matrices are `__half` (FP16). Scalars alpha and beta are `float`.
Accumulation should be done in FP32 for numerical stability.

## Memory Layout

All matrices are **row-major**:
- A: Element (i,k) at `A[i * lda + k]`. lda >= K.
- B: Element (k,j) at `B[k * ldb + j]`. ldb >= N.
- D: Element (i,j) at `D[i * ldd + j]`. ldd >= N.

## Build & Test

```bash
make test                    # requires solution.h in task directory
./test                       # default: runs small/medium/large sizes
./test 1024 1024 1024        # custom single size: M N K
./test 1024 1024 1024 1.0 0.0 20  # M N K alpha beta iterations
```

Correctness is verified against a reference implementation at multiple problem sizes
(small: 1024x1024x1024, medium: 4096x4096x4096, large: 8192x8192x8192).
Performance is timed for both reference and your solution at each size.

CUTLASS headers are available on the include path.
