# Task: 39_gemm_permute

Half-precision General Matrix Multiply (HGEMM), row-major layout.

## Function Signature

Implement the following function in `solution.h`:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp16.h>

cudaError_t GemmPermute(
    int M, int N, int K, float alpha,
    __half const *A, int lda,
    __half const *B, int ldb,
    float beta,
    __half *D, int ldd);
```

## Operation

D = alpha * A * B + beta * D

Where:
- A is M x K
- B is K x N
- D is M x N

## Data Types and Precision

All matrices are `__half` (FP16). Scalars alpha and beta are `float`. Products of the FP16
inputs must be accumulated in FP32 and the result rounded to FP16 once at the end; lower-precision
arithmetic (FP16 or BF16 accumulation, FP8 or INT8 operands) is not allowed even if it passes the
tolerance.

## Memory Layout

All matrices are **row-major**:
- A: Element (i,k) at `A[i * lda + k]`. lda >= K.
- B: Element (k,j) at `B[k * ldb + j]`. ldb >= N.
- D: Element (i,j) at `D[i * ldd + j]`. ldd >= N.

## Build & Test

```bash
make test                    # requires solution.h in task directory
./test                       # default: runs all benchmark sizes below
./test 16384 10240 5120      # custom single size: M N K
./test 16384 10240 5120 1.0 0.0 20  # M N K alpha beta iterations
```

## Problem Sizes

The linear layers of Qwen3-32B served on one GPU (hidden 5120, 64 query / 8 KV heads of
dimension 128, FFN 25600, vocabulary 151936); M = tokens, either a 16K-token prefill chunk or
one decode step of 128 concurrent sequences:

| label            | M     | N      | K     | layer                                  |
|------------------|-------|--------|-------|----------------------------------------|
| decode_qkv       | 128   | 10240  | 5120  | fused QKV projection, decode           |
| prefill_qkv      | 16384 | 10240  | 5120  | fused QKV projection, prefill          |
| prefill_o_proj   | 16384 | 5120   | 8192  | attention output projection, prefill   |
| prefill_mlp_up   | 16384 | 51200  | 5120  | fused gate+up projection, prefill      |
| prefill_mlp_down | 16384 | 5120   | 25600 | down projection, prefill               |
| decode_lm_head   | 128   | 151936 | 5120  | LM head, decode                        |

alpha = 1, beta = 0, lda = K, ldb = ldd = N. With beta = 0 the initial contents of D are
arbitrary finite values that must not affect the result.

## Correctness

Inputs are random FP16 values in [-1, 1) that use the full FP16 significand. Every element of D
is compared with the exact result:
- every element must be finite and satisfy |D - exact| <= 1.5e-3 * |exact| + 2e-4 * RMS(exact)
  (three times the FP16 rounding bound plus a small accumulation allowance);
- the relative Frobenius error ||D - exact|| / ||exact|| must be <= 7.5e-4.
Elements that are not written fail the check.

Performance is timed for both the reference and your solution at each size; the task score is
the geometric mean of the per-size speedups.

CUTLASS headers are available on the include path.
