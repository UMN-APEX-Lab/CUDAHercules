# Task: tk_fp8_gemm

## Target Hardware
NVIDIA Blackwell GPU (SM100/SM120).


FP8 (E4M3) General Matrix Multiply on B200, matching ThunderKittens Blackwell performance.

## Function Signature

Implement in solution.h:

```cuda
#pragma once
#include <cuda_runtime.h>
#include <cuda_fp8.h>
#include <cuda_fp16.h>

void Fp8Gemm(__nv_fp8_e4m3 *A, __nv_fp8_e4m3 *B, half *C, int M, int N, int K);
```

## Operation

C = A * B^T

Where A is M×K (row-major, FP8 E4M3), B is N×K (transposed, FP8 E4M3), C is M×N (row-major, FP16 half).

**IMPORTANT**: B is stored as [N,K]. The GEMM computes C = A * B^T. Output is FP16 half (not FP8).
